# Вводная по NHL 13

Сводка от 7 октября 2026 года. Цифры по базе получены из анкерных файлов
nhl-modding-studio; на собственном образе ещё не проверены.

## Цель

- Личный нативный порт NHL 13 (Xbox 360, TitleID `4541099B`) на Windows, играть с
  геймпада. Без распространения. Есть оригинальный диск и консоль.
- Главное — глубокая кастомизация базы: составы, устройство лиг (например, число
  команд в лиге) и текущий год, чтобы возраст игроков был правильным.
- Эмулятор как итоговая платформа отвергнут: нужна правка кода. Для справки: в Xenia
  Canary NHL 13 играбельна с `readback_resolve = "full"`.

## База `nhlng.db`

| Что | Факт |
|---|---|
| Объём | 136 таблиц, ~80 тыс. записей. 360 и PS3 совпадают побайтово. TDB v6, big-endian, записи упакованы по битам |
| Команды | `exhibitionteams`: 248 строк, только правка. Номер команды 8-битный, потолок 255 |
| Франшиза | В `leagueteams` не больше 128 команд |
| Лиги | Код лиги — 4 бита, 16 лиг: NHL, AHL, SHL, Liiga, DEL, Extraliga, NLA, GET, сборные, OHL, QMJHL, WHL, проспекты, кастомные, Winter Classic, EASHL. Конференция и дивизион — по 6 бит, поля таблицы команд |
| Календари | 10 лиг, у каждой своя таблица матчей; строки можно добавлять и удалять |

| Календарь | Строк | Команды × матчи / 2 |

| АХЛ | 1140 | 30 × 76 / 2 |
| SHL | 330 | 12 × 55 / 2 |

### Можно ли менять число команд в лиге

- **Данные:** перетасовать, переименовать, переукомплектовать — да. Новые клубы
  делаются из ненужных слотов (сборные, юниоры).
- **Проверить:** изменить число команд — скорее да (перенос между лигами +
  новый календарь), но может быть зашито в коде таблицы, сетки плей-офф или UI.
- **Код:** НХЛ на 32 команды с дивизионами и плей-офф — только правкой кода, без
  гарантий.

## Текущий год и возраст

- В `nhlng.db` поля «текущий год» нет. Годы абсолютные: 8 бит + 1900 (потолок 2155).
  Рождение 1960–1996, драфт-пики 2013–2018, статистика до 2012.
- Даты — 16 бит, дни от 30.12.1899 (как в Excel), потолок 2079.
- В сейвах франшизы и сезона есть таблица `leaguestates` (`key`, `value`, `tier`, `type`):

| type / key | value | Смысл |
|---|---:|---|
| 0 / 0 | 41176 | Текущая дата лиги: 24.09.2012 (в сейве сезона 41190 = 08.10.2012) |
| 13 / 78 | 2012 | Год сезона |
| 23 / 138 | 82 | Матчей в сезоне |
| 15 / 90 | 525000 | Минимальная зарплата 2012/13 |
| 18 / 108 | 54200000 | Нижний порог платёжной ведомости |
| 19 / 114 | 70200000 | Потолок зарплат |
| 20 / 120 | 30 | Вероятно, число команд (не проверено) |

### Три способа сделать возраст правильным

1. **Сдвиг годов, без кода.** Вычесть 13 из всех годов в составах. Запасной вариант:
   на экране годы сдвинуты.
2. **Правка сейва.** Франшиза → в `leaguestates` год 2025, дата — сентябрь 2025,
   финансы 2025/26 (потолок 95,5 млн, порог 70,6 млн, минималка 775 тыс.), сдвиг
   драфт-пиков. Вопрос: примет игра значения или пересчитает.
3. **Правка кода в порте.** Найти, где новая франшиза берёт 2012 год и дату. Правильное решение.

Не выяснено: откуда Play Now и экран составов берут возраст (константа или часы
консоли); есть ли «2012-13» в строках локализации; задаётся ли стартовый год в коде
или в конфиге внутри `.big`.

## Следующие шаги

1. Получить файлы игры и распаковать: образ — `xdvdfs.py`, GoD — отдельно, `.big` —
   `unpack_big.py`.
2. Найти `nhlng.db` (по заметкам NHL 12, вероятно, в `data0.big`) и сравнить с
   анкерной базой.
3. Поискать в архивах конфиг со стартовым 2012 годом.
4. Распаковать `default.xex` (LZX) и искать 2012 и даты около 41100–41200.
5. Эксперимент со сменой года через `leaguestates`.
6. Параллельно — порт по схеме Legacy: генерация кода ReXGlue, недостающие функции,
   таблицы переходов, патчи SDK.
