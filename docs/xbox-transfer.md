# Как достать файлы с приставки

## Приставка в сети (разведка 07.10.2026)

| Что | Значение |
|---|---|
| IP | `192.168.1.244` (DHCP, может смениться — лучше закрепить в роутере) |
| MAC | `00:22:48:C7:E7:58` (Microsoft) |
| Порт 21 | FTP Aurora, баннер `220 FtpDll Ready`. Анонимный вход не принимает (`530 Need username`) |
| Порт 9999 | NOVA webUI Aurora, `X-Security-Enabled: 1` — тоже с логином |
| Порт 80 | Открыт, на `GET /` ничего не отвечает |

На ПК включён системный прокси `127.0.0.1:12334`: `Invoke-WebRequest` к приставке
идёт через него и получает 502. Ходить к Xbox напрямую — сокетом или `curl.exe`
с `--noproxy '*'`.

## Логин FTP

Логин и пароль хранятся в `%USERPROFILE%\_netrc`, вне репозитория (по умолчанию в
Aurora оба `xboxftp`, меняются в её настройках). Файл заводится руками один раз:

```powershell
$u = Read-Host 'Логин FTP'; $p = Read-Host 'Пароль FTP'; "machine 192.168.1.244 login $u password $p" | Set-Content -Encoding ascii "$env:USERPROFILE\_netrc"
```

Проверка — корень FTP:

```powershell
curl.exe --noproxy '*' --netrc-file "$env:USERPROFILE\_netrc" ftp://192.168.1.244/
```

## Где искать NHL 13 на приставке

| Что | Путь |
|---|---|
| Games on Demand | `Hdd1/Content/0000000000000000/4541099B/00007000/` — файл-заголовок и папка `<он же>.data/Data0000…` |
| Установка с диска | `Hdd1/Content/0000000000000000/4541099B/00004000/` |
| Распакованная игра | любая папка с `default.xex` и `.big` (часто `Hdd1/Games/…`) |
| Апдейт игры | `Hdd1/Content/0000000000000000/4541099B/000B0000/` |
| Сейвы | `Hdd1/Content/<профиль>/4541099B/00000001/` |

Всё скачанное кладётся в `game/raw/` — папка в `.gitignore`.

## Флешка вместо FTP

Флешки под Xbox 360 — FAT32, предел файла 4 ГБ. GoD (куски `Data0000…` по ~160 МБ)
и распакованная папка пролезают, цельный `.iso` — нет.
