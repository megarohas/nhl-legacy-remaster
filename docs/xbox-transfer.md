# Как достать файлы с приставки

## Приставка в сети (разведка 07.10.2026)

| Что | Значение |
|---|---|
| IP | `192.168.1.244` (DHCP, может смениться — лучше закрепить в роутере) |
| MAC | `00:22:48:C7:E7:58` (Microsoft) |
| Порт 21 | FTP Aurora, баннер `220 FtpDll Ready`. Анонимный вход не принимает (`530 Need username`) |
| Порт 9999 | NOVA webUI Aurora, `X-Security-Enabled: 1` — тоже с логином |
| Порт 80 | Открыт, на `GET /` ничего не отвечает |

Софт: Aurora `0.7b Rev1655` (= 0.7b.2 от ноября 2021, последняя, новее не выходило),
DashLaunch 3.x без плагинов. Логи Aurora — `Hdd1/Aurora/Data/Logs/debug.log` и
`debug.log.last` (прошлый сеанс), там же старые `*.crash.log`.

Приставка дважды намертво зависала (пропадала даже из ARP, в логе обрыв без записи
о падении) — оба раза с загруженным `Nova.xex` (веб-интерфейс). После его
отключения FTP-сессии и скачивание работают стабильно. Держать веб-интерфейс
выключенным, порты 80 и 9999 не трогать.

На ПК включён системный прокси `127.0.0.1:12334`: `Invoke-WebRequest` к приставке
идёт через него и получает 502. Ходить к Xbox напрямую — сокетом или `curl.exe`
с `--noproxy '*'`.

## Логин FTP

Логин и пароль хранятся в `%USERPROFILE%\_netrc`, вне репозитория (по умолчанию в
Aurora оба `xboxftp`, меняются в её настройках). Файл заводится руками один раз:

```powershell
$u = Read-Host 'Логин FTP'; $p = Read-Host 'Пароль FTP'; "machine 192.168.1.244 login $u password $p" | Set-Content -Encoding ascii "$env:USERPROFILE\_netrc"
```

Проверка — корень FTP:

```powershell
curl.exe --noproxy '*' --netrc-file "$env:USERPROFILE\_netrc" ftp://192.168.1.244/
```

## Где искать NHL 13 на приставке

| Что | Путь |
|---|---|
| Games on Demand | `Hdd1/Content/0000000000000000/4541099B/00007000/` — файл-заголовок и папка `<он же>.data/Data0000…` |
| Установка с диска | `Hdd1/Content/0000000000000000/4541099B/00004000/` |
| Распакованная игра | любая папка с `default.xex` и `.big` (часто `Hdd1/Games/…`) |
| Апдейт игры | `Hdd1/Content/0000000000000000/4541099B/000B0000/` |
| Сейвы | `Hdd1/Content/<профиль>/4541099B/00000001/` |

Всё скачанное кладётся в `game/raw/` с теми же путями, что на FTP (`game/raw/Hdd1/…`) —
папка в `.gitignore`.

## Что нашлось (07.10.2026)

| Что | Путь на `Hdd1/Content/` | Размер |
|---|---|---:|
| Установка с диска: заголовок `CON`, тип `00004000`, «NHL™ 13» | `0000000000000000/4541099B/00004000/DE1A9BB72C06CB1041B3EC10583EFE34` | 44 КБ |
| Данные установки: `Data0000`–`Data0037` (37 × 170 459 136 + 46 383 104) | `…/DE1A9BB72C06CB1041B3EC10583EFE34.data/` | 5,92 ГБ |
| Апдейт TU2, пакет `LIVE` | `0000000000000000/4541099B/000B0000/tu00000002_00000000` | 9,7 МБ |
| Сейвы: PROFILE, BUILDYOURAI, HOCKEYCARD, 4 × DYNASTY (франшиза) | `E00008D448C7E758/4541099B/00000001/` | 38 МБ |

В двух других профилях (`E000005148C7E758`, `E000098F48C7E758`) NHL 13 нет.
Скорость FTP — около 10 МБ/с, вся игра — минут 10–11. Установка с диска — тот же
контейнер SVOD, что и GoD: данные игры целиком, диск нужен только для запуска на консоли.

Список файлов одной сессией:

```bash
curl.exe -sS --noproxy '*' --netrc-file "$USERPROFILE/_netrc" --disable-epsv --ftp-skip-pasv-ip ftp://192.168.1.244/Hdd1/Content/0000000000000000/4541099B/
```

`--ftp-skip-pasv-ip` — на случай, если Aurora пришлёт в ответе PASV чужой адрес.

## Флешка вместо FTP

Флешки под Xbox 360 — FAT32, предел файла 4 ГБ. GoD (куски `Data0000…` по ~160 МБ)
и распакованная папка пролезают, цельный `.iso` — нет.
