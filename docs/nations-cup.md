# Кубок наций в франшизе (ветка `nations-cup`, эксперимент, с 20.10.2026)

Идея пользователя: в межсезонье «Be a GM» — августовский турнир сборных (групповой этап + плей-офф). Сборную
выбираешь каждый год из списка предложений (по успехам прошлого сезона), состав набираешь фэнтези-драфтом из
игроков своей страны; статистика турнира у игроков и достижения тренера сохраняются и видны.

## Режим турнира игры (прогон на копии userdata-natcup, 20.10)

- **PLAY → TOURNAMENTS → TOURNAMENT MODE → EA SPORTS WORLD TOURNAMENT** (рядом — Mastercard Memorial Cup, Playoff
  Mode, Battle for the Cup). Команд 8 или 16 (по умолчанию сборные: на 8 — A: CAN, SWE, RUS, GER; B: USA, FIN, CZE,

  две группы, круг внутри группы, затем все 8 — в четвертьфинал крест-накрест (A1–B4, A2–B3, B1–A4, B2–A3). Команду
  можно заменить любой из любой лиги (кнопка X), людьми — любые. **Составы сборных — стоковые, старые.**
- **Сейв `TOURNAMENT <UTC>`** (3,6 МБ, ZlibV4, «TournamentFile», 31 таблица `league*`, хвост 91 868 байт не разобран):
  `leagueteams` (index 0–7, teamid сборной, league 8, context 0 → 4 в плей-офф), `leaguescheduletable` (home/away —
  индексы команд, month/day с нуля, round 0 круг / 2 четвертьфинал), результаты — `leaguegamestats`, таблица —
  `leagueteamplayoffsstats` (reg_w…), статистика игроков — `leagueplayerplayoffsstats` (team = индекс + 1; полевые:
  f14 GP, f06 G, f07 A, f05 PIM, f11 +/- (+512), f12 PPG, f15 GWG; вратари: f02 броски, f03 пропущено, f13 победы),
  составы — `leaguerostertable` (194 игрока), `leaguestates` type 0 — дата, 1/2 — фаза. Группа отдельным полем не
  хранится. Разбор — `game/work/natcup-research/tourn_db.py` (только чтение).
- Лог порта в турнире: «team stats table broken (8 records)» — ложное срабатывание проверки `nhllegacy_teams.cpp`.

## API движка для турнира (статический разбор 20.10)

- **Даты:** эпоха 1.01.1900 = 0; 82E27EC0(&out, год, месяц, день) / 82E27F98(&serial, &год, &месяц, &день) — месяц и
  день с нуля; 82E27E98(&serial) — день недели (5 — пятница). В календаре month/day тоже с нуля.
- **Состав команды T:** удалить — 82A1BB18(—, T) (`DELETE … WHERE team = T` в `leaguerostertable`); записать —
  82A29D48(tmp, T, &R): tmp — 16 байт (82BA65C8 / 82BCC4A0), R — 3244 байта (829748A0 + 82657880(R, 0, 3244)):
  +1 s8 число игроков, +2+2i u16 playerindex, +84+4i rosterstatus, +244+i jersey, +284+i playerstyle, +324+2i /
  +325+2i капитан/ассистент, +404+71i… флаги звеньев (0); до 40 строк на команду. Номер/стиль игрока — 82B0DBA8(A),
  82B0DEF0(B), 82B38768(A, playerindex, B, 1): B+418 номер, +121 позиция (4 — вратарь), +153/+162 стиль, +123/+124
  страна, +108 год; 82B0DC20(A). Пятёрки — L ≥ 456 байт: 82B87538(L, T, tag), 82B7E6E8(L), 82B871F8(L), 82B87870(L)
  (tag — счётчик кэша 0x83BDC550: звёзды 149, проспекты 194). Объект Матча звёзд (82A3ECE8, 82A3E960) пишет только в
  пары команд X, X+1 и ≤ 20 игроков — не годится.
- **Игра в календарь:** 82BEC748(—, &G), G 44 байта: +0 vtable 0x82046474, +8 month, +12 day (с 0), +16 home, +20 away,
  +28 status 0 (2 — отменена), +32 round (1…4 — плей-офф), +36/+40 → уровень 82975FA0. Игры дня всех уровней симит
  82A26050 → 82A33CA8 (сыграна — есть строка `leaguegamestats`), итоги уровня — задача 2 (82B41860, фильтр по уровню).
  Удаления строк календаря в коде нет (status 2 или DELETE по образцу 82A1BB18).
- **Управление:** 82B1B048(82AF8BF0(), команда, флаг 0 — пользователь) → флаг в списке уровня (+244+4i) и маска
  `leaguestates` type 3 (номер в списке уровня < 31); несколько пользовательских команд на уровне допустимы
  (82AFB898/82AFB910, IsUserControlled 82B28010). Где календарь решает «играть или симить» — не найдено.
- **Цена замены QMJHL:** 82B099E0 (создание) пересчитывает `juniorteam` одним сдвигом 154 − первый номер OHL —
  верно, только пока OHL, QMJHL, WHL идут подряд: юниоры QMJHL укажут на сборные, WHL сдвинутся на 2 → нужен свой
  пересчёт; генератор новичков (82B37120/82B373C8/82B37598 → 82B009D8) может дать лигу 10. Сборным при создании
  пишутся стоковые составы (82B3DFC8 → 82A29D48) — дубли игроков клубов, чистить 82A1BB18 сразу после 82B4A540.
  Мемориальный кубок — только Be a Pro; «тип уровня» 82AFCE98 у лиги 8 = 3 (плей-офф 82B434B8, фаза 82B0C700).

## План встраивания (по образцу Матча звёзд + Мемориального кубка)

1. Своя задача (тип 0/1, хук на 82B4C3A0) в августе: собрать сборные, составы (драфт), расписание.
2. Сборные — временные команды на заёмных местах (сейчас все 126 заняты: варианты — места CHL на время турнира,
   места звёзд/проспектов, или поднять предел).
3. Игры — строки `leaguescheduletable` в августе (их сыграет тип 2), «сыграть?» — как сообщения 50/51.
4. После турнира — убрать временные строки, итоги и статистику — в свою историю (и в карточку игрока: event 5+ с хуком
   подписи).
