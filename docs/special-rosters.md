# Сборные, Матч звёзд и вратарь тренировки (`tools/legacy_data/special_rosters.py`)

Особые команды Legacy — 21 сборная (строки `exhibitionteams` 133–153, лига 8) и две команды Матча звёзд для Play Now
(222 «Green / Red», 223 «Black / Blue»). До 03.11.2026 в них стояли составы базы EA 2015 года: Тэйвз, Прайс, Кроуфорд,
братья Костицыны. Инструмент собирает их заново и, как [roster_update.py](roster-update.md), пишет и базу, и файл
`ROSTER ДД.ММ.ГГГГ`: игра берёт составы из сохранённого ростера, а не из базы. С 03.11.2026.

```bash
python tools/legacy_data/special_rosters.py run --dry-run      # всё посчитать, записать только отчёт
python tools/legacy_data/special_rosters.py run                # база и ROSTER в game/work/special-rosters/out
python tools/legacy_data/special_rosters.py show RUS EAS WES   # состав и звенья команд установленной базы (--db — другой)
```

| Параметр | Что | По умолчанию |
|---|---|---|
| `--only nations` / `allstar` | только сборные / только Матч звёзд | всё |
| `--nhl27 A,B` | какие сборные брать из NHL 27 | все, кроме `--own` и `--keep` |
| `--own A,B` | какие сборные собирать по своей спеке | `RUS` |
| `--keep A,B` | какие не трогать | никакие |
| `--spec ФАЙЛ` | спека своих сборных | [special_rosters_nations.txt](../tools/legacy_data/special_rosters_nations.txt) |
| `--db`, `--save` | база, на которой сделан сейв (схема рядом), и сейв ROSTER | установленная база, новейший ROSTER |
| `--db27` | база NHL 27 | `game/work/nhl27/db/nhl_game.db` ([import-from-ea.md](import-from-ea.md)) |
| `--date ДД.ММ.ГГГГ` | дата в имени ростера | сегодня |
| `--out`, `--launcher`, `--dry-run` | куда писать; чем проверять ростер; проба | `game/work/special-rosters/out`; свежий лаунчер |

Сейвы и база пользователя только читаются, установка — командами в конце `report.md`. Повторный запуск на готовой базе ничего
не меняет (проверено 03.11.2026: побайтно та же база).

## Сборные из NHL 27

В базе NHL 27 три набора сборных: лига 10 — best-on-best (у Канады Макдэвид, Кросби, Маккиннон; 24 страны), 25 — чемпионат
мира 2026, 24 — молодёжные. Берётся лига 10: она 1:1 ложится на сборные Legacy (те же 21 аббревиатура; Венгрии, Словении и
Кореи у Legacy нет).

- **Свой игрок.** Кто есть в нашей базе (имя и дата рождения — `roster/match.py`, как у конвейера), тот идёт в сборную как есть:
  клуб, атрибуты, голова, контракт — наши, они свежее. В сборной у него своя запись состава и своя связь `exhibitionplayers`,
  номер — как в сборной NHL 27 (в биографии остаётся клубный). Если дата у EA другая, а в прежнем составе этой сборной есть
  ровно один человек с тем же полным именем, это он (так сшиты все игроки Казахстана).
- **Игрок только сборной.** Кто у нас есть, но без клуба и не в пуле свободных агентов, — других данных о нём нет: биография и
  атрибуты из NHL 27, голова и портрет свои (03.11.2026: 70 игроков, в основном Япония, Казахстан, Польша).
- **Новый игрок.** Кого у нас нет, тот занимает строку игрока, который был только в сборной и выбыл (сначала своей страны, потом
  другой, старшие первыми), потом строку игрока без клуба. Биография и атрибуты — из NHL 27 так же, как у `league27.py`
  ([legacy-data.md](legacy-data.md), «Лиги из NHL 27»), но без прав и контракта НХЛ (как у ветеранов: игрок только сборной во
  франшизу не попадает). Голова — типовая того же тона кожи, портрета нет, статистика прежнего владельца строки (карьера и
  международные турниры) убирается. 03.11.2026 таких 99: Австрия 19, Великобритания 17, Италия 15, Украина 14, Франция 12…
- **Звенья, буквы, номера** — из NHL 27; если в данных дыра (кто-то не нашёл строку), звенья по рейтингу (`roster/lines.py`).
  Основной вратарь — сильнейший из двух по OVR игры (как в `roster_update.py`): у Канады Томпсон (90), а не Биннингтон (86).
- **Выбывший** из сборной, у которого нет клуба, становится игроком без клуба (`team` 0), как ветераны.

## Свои сборные: Россия

В NHL 27 Россия есть, но EA не обновляет её с 2022 года: Тарасенко и Гусев без клуба, нет Демидова и Мичкова. Поэтому
Россия собирается по спеке [special_rosters_nations.txt](../tools/legacy_data/special_rosters_nations.txt): строка
`RUS | G: … | D: … | F: … | L1: … | D1: …`, игроки — по именам из нашей базы, `[C]`/`[A]` — буквы, `(VAN)` — клуб для тёзок,
первые два вратаря — основной и запасной. `L1`–`L4` — тройки «левый - центр - правый», `D1`–`D3` — пары «левый - правый»
(все семь или ни одного; без них — звенья по позициям, как у Матча звёзд). Строка `XXX | +F: игрок` (или `+G`, `+D`) — не
своя сборная, а добавка к сборной из NHL 27 (так Пинчук в Беларуси). Большинство, меньшинство, овертайм, буллиты — по
рейтингу среди тех же 20 одетых. Кого в базе нет, инструмент называет в отчёте и пропускает.

Правило отбора (03.11.2026, записано в спеке): кандидаты — игроки из разборов «какой была бы сборная России на Олимпиаде-2026»
(ESPN 13.01.2026, CBS Sports 10.02.2026, The Big Lead 17.02.2026) и списков лучших россиян НХЛ 2025/26 (news.ru 16.04 и
11.10.2026), которые в 2026/27 играют в клубе НХЛ нашей базы; из них по OVR игры — 3 вратаря, 8 защитников, 15 нападающих.
Все 26 в базе есть; Овечкин (WSH) и Малкин (PIT) по NHL.com подписали контракты на 2026/27.

Звенья России — вручную в спеке. **Центры — решение пользователя 03.11.2026**: «центры пусть будут: Малкин — Барбашев — Буч —
Наместников» (звенья 1–4; Юров и Тренин — не в центр). Крайние — по сыгранности (DailyFaceoff 30.10–02.11.2026 и новости):
Капризов — Малкин — Кучеров; Овечкин — Барбашёв — Дорофеев (Барбашёв и Дорофеев — тройка Айкела в плей-офф 2026); Панарин —
Бучневич — Свечников (Панарин и Бучневич — «Рейнджерс», 2021); Юров — Наместников — Мичков. Пары: Сергачёв — Зуб (Зуб —
единственный праворукий), Гавриков — Никишин, Задоров — Орлов. Запасные: Тренин, Демидов и Марченко (травмированы на 02.11),
Шестёркин, Проворов, Романов. Обоснование — в комментарии спеки.

Новый состав — правка строки спеки и `run`. Другую страну так же: строка в спеке и `--own RUS,XXX`.

## Матч звёзд (Play Now)

Команды те, что есть в игре: 222 «Green / Red» (`EAS`, конференция 2 — Восток) и 223 «Black / Blue» (`WES`, конференция 1 —
Запад). Правило:

1. Кандидаты — игроки составов клубов НХЛ своей конференции; сила — OVR, который считает игра (`ovrformula.game_ovr`).
2. По 24 игрока: 3 вратаря, 8 защитников, 13 нападающих — лучшие по OVR; равный OVR решают очки регулярного чемпионата
   прошлого сезона (у вратарей — победы), потом возраст (моложе выше).
3. От каждого из 16 клубов — минимум один, как в настоящем Матче звёзд. Клуб без представителя получает того своего игрока,
   чья замена меньше всего ослабляет команду по OVR: он встаёт на место самого слабого выбранного того же амплуа из клуба,
   где выбраны двое и больше; при равной потере — сильнейший игрок клуба.
4. Центров не меньше четырёх.
5. Звенья — по позициям (`pos_lines`, правка пользователя 03.11.2026: «в центре — центры, крайние по своей стороне, пары
   лево/право, по возможности одноклубники вместе»):
   - центры — четыре сильнейших из тех, кто играет в центре: своя позиция C в базе или центр звена своего клуба на странице
     DailyFaceoff (кэш `roster_update.py`); OVR выбирает только среди них;
   - крайние — восемь сильнейших из остальных: сначала одноклубники центров — к своему центру, потом от сильнейшего — в верхнее
     звено со свободной своей стороной (позиция L/R, у центра на краю — по хвату), иначе на другую;
   - пары — леворукие слева, праворукие справа, сначала одноклубники, потом по силе; вратари — двое сильнейших;
   - большинство, меньшинство, овертайм, буллиты — по рейтингу среди тех же 20 одетых.
6. C — у лучшего полевого по OVR, A — у двух следующих; номера клубные, совпавшие — ближайший свободный.

03.11.2026: Восток — центры Кросби, Барков, Джек Хьюз, Сузуки (с ним Кофилд, с Барков Рейнхарт), Кучеров (C), Пастрняк,
Мэттьюс, Вернски, Далин, в воротах Василевский и Сорокин; Запад — центры Макдэвид (C), Маккиннон (с ним Нечас), Драйзайтль,
Селебрини, Капризов, Куинн Хьюз — Макар, в воротах Вульф и Найт
(Эттингер уступил место по пункту 3: Сент-Луис представлен Биннингтоном, а других игроков Далласа хватает). Полностью — в
`report.md`.

## Вратарь тренировки

Откуда Кроуфорд: не из таблиц. Когда вратарь тренировки не выбран (поле −1), функции `82AB0DE0` и `82AB2C88` ищут его по имени:
`sub_82B29980(запрос, «Corey», «Crawford»)` — запрос к базе по имени и фамилии, строки зашиты в образе (`0x8207C174`, 8 байт, и
`0x8207C17C`, 12 байт; `tools/xrefs.py refs 8207c150 8207c190`). Тем же способом игра ищет полевых по умолчанию: «Jonathan
Toews» (те же функции) и «Zdeno Chara» (`82A86448`, CPracticeIonAdapter). Базой это не поменять: другое имя не найдётся.

Поэтому — врезка порта `src/nhllegacy_practice.cpp`: перед первым таким запросом на место зашитых строк кладутся имя и фамилия
из cvar `nhl_practice_goalie` (по умолчанию `Andrei Vasilevskiy`; имя до 7 байт, фамилия до 11; пусто — Кроуфорд). Полевые
по умолчанию не меняются.

Где это видно (проверено 03.11.2026 на копии): CUSTOMIZE → CREATION ZONE → EDIT PLAYER → игрок → `START` (Test On Ice) — в
воротах Василевский (№ 88, синяя маска), в журнале игры `practice goalie: Andrei Vasilevskiy`. В Free Skate, сценариях
вратаря и обучении поиск по имени не вызывается: там вратарь выбранного клуба или пустые ворота.

Чтобы поиск по имени не промахнулся, строки этих игроков (`NAME_LOOKUP` в `add_players.py`: Чара, Тэйвз, Кроуфорд,
Василевский) не берутся донорами ни здесь, ни в `add_players.py`/`roster_update.py`, даже если игрок остался без клуба: после
пересборки Тэйвз, Кроуфорд и Чара именно такие.

## Что меняется

| Таблица | Что |
|---|---|
| `exhibitionrostertable` | записи 20 сборных и обеих команд Матча звёзд: звенья, одетые, буквы, номера; число записей 5499 → 5499 |
| `exhibitionplayers` | связь записи: прежняя этого игрока в той же команде, иначе его ничья, иначе освободившаяся (`playerid` — новому); 03.11.2026 переназначено 315, новых 0 |
| `exhibitionplayerbiotable` | новые и игроки только сборных: все поля NHL 27 (имя, дата и место рождения, гражданство, рост, вес, хват, амплуа, драфт, игры), `team`, `jersey`, контракт и права — 0, у новых `headid`, `skincolor`, `hasportrait` 0, `audioid` 0; у выбывших без клуба — `team` 0 |
| `exhibitionskaterai`, `exhibitiongoalieai` | у тех же — атрибуты, стиль, тенденции, черты, рост из NHL 27 |
| `stockcareer*`, `stockintltourney*` | статистика прежних владельцев строк-доноров убрана (только в базе, в сейве таких таблиц нет) |

Клубы, пул свободных агентов, формы, экипировка, арены не трогаются. Головы — только у новых игроков (типовые). Слияние с
ростером пользователя — `roster_merge.py` ([legacy-data.md](legacy-data.md), «Перенос в сейв ROSTER»): правки пользователя
остаются, места таблиц сейва те же (окна «damaged» нет), лаунчер `--check-roster` принимает файл.

## Как проверить

```bash
python tools/legacy_data/special_rosters.py show RUS CAN EAS WES --db game/work/special-rosters/out/db/nhlng.db
python tools/tdb.py verify "game/work/special-rosters/out/ROSTER 03.11.2026" --meta nhl-legacy-port/userdata/cache/guest/db/nhlng-meta.xml
```

В игре: Play Now → команды `Green / Red` и `Black / Blue`, экран составов; сборные — CUSTOMIZE → ROSTER
MANAGEMENT → EDIT LINES (`LB`/`RB` — команда) или Play Now → лига National → Starting Lineups (проверено 03.11.2026: звенья
России и Eastern All-Stars в игре такие же, как в базе, меню без окна «damaged»). Вратарь Кроуфорд, по словам пользователя, —
в редакторе игрока при проверке на льду (CUSTOMIZE → Creation Zone → Edit Player → `START`); после врезки там Василевский.

## Грабли

- Порядок с другими инструментами: `roster_update.py` переводит игроков между клубами и не трогает сборные; после нового ростера
  клубов этот инструмент можно запускать заново (`--db`/`--save` — их результат), сборные сами возьмут новые клубы.
- `build-all.sh` про особые команды не знает: после полной пересборки базы — запустить заново.
- Состав сборной NHL 27 меняется только с новой базой NHL 27; свои сборные — правкой спеки.
- Если доноров не хватит (сборная из NHL 27 с десятком новых вратарей), лишние останутся без строки — они в отчёте, в разделе
  команды «Нет в составе».
