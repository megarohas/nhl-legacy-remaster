# Пул драфта франшизы: откуда он берётся и почему в нём составы CHL 2012 года (09.10.2026)

Разбор по копиям сейвов франшизы на 32 команды: NHL 13 — `game/work/nhl13-test/…` агента nhl13-franchise,
NHL Legacy — `legacy-port/userdata/…`. Считались только живые строки (`Tdb.live_rows`,
[save-editing.md](save-editing.md) «Живые записи»). Копии сейвов и скрипты разбора лежат в
`game/work/draftpool/`.

## 1. Коротко

- **Пул первого драфта собирается один раз — при создании франшизы.** Он лежит в сейве в таблице
  `leaguerookiedata` (до 1500 строк, ключ `playerid` = `leagueplayerbiotable.index`). На драфте игра только
  перечитывает эту таблицу и ничего не догенерирует.
- В пул попадают игроки с `isdraftable` = 1, у которых `draftyear` ≤ год сезона + 1. В базе `isdraftable` = 0
  у всех, флаг ставит создание франшизы:
  - **всем игрокам клубов CHL (OHL, QMJHL, WHL) без прав НХЛ (`proteam` 0), возраст не проверяется**;
  - остальным игрокам без прав НХЛ (Европа, без клуба) — только если к драфту им не больше 20 лет;
  - `draftyear` игра пересчитывает сама: год рождения + 18 (+ 19, если родился после 15.09).
- Если реальных игроков какой-то юниорской лиги меньше квоты лиги, игра догенерирует вымышленных до квоты.
  Квоты берутся из таблицы `ResourceKernel::RookieGen` (`fe/resource_kernel/rookiegen.brk`). Проверено в игре:
  без старых игроков CHL класс — 262, из них вымышленных CHL WHL 40, OHL 40, QMJHL 35 (§4).
- Составы CHL в исходной базе — 2012 года, и у нас они остались такими же. Поэтому в пуле 1198 юниоров
  1991–96 г. р. (им 30–35 лет) и 51 игрок 1971–89 г. р. Из них 48 — ушедшие из НХЛ: конвейер сажал их на места
  юниоров, перешедших в НХЛ. Ещё 3 — свои игроки базы EA в SHE. Квоты CHL перекрыты в разы, поэтому вымышленные создаются только для 8 лиг вне CHL.
- Ветераны «без клуба» в пул не попадают. Это `team` = сборная/легенды + 1 или 0 без записи в
  `exhibitionfreeagents`: во франшизу такие игроки не импортируются.
- **Пенсия во франшизе — это удаление записей игрока** (`leagueplayerbiotable`, `leagueskaterai`,
  `leagueskaterequipment`; у вратарей — свои таблицы) и строка в `leagueretirementtable`: имя, `playerartid`,
  клуб, амплуа, игры, `stat1`/`stat2` (у полевых — голы и передачи: Per-Johan Axelsson 797 / 103 / 184).
  В тестовой франшизе между 10.06 и 20.06.2027 так ушли 112 игроков 1976–84 г. р., почти все без клуба во
  франшизе (бывшая Европа 2012 года). Признака «на пенсии» у живой записи нет ни в сейве, ни в базе. `active` = 0
  в `exhibitionplayerbiotable` — это только 180 пустых слотов создаваемых игроков; ставить его настоящим игрокам
  не проверено, а их записи в составах остались бы висячими. Поэтому «отправить на пенсию» в базе значит
  оставить игрока без клуба: `tools/roster write --retire-veterans` ([roster-pipeline.md](roster-pipeline.md)).

Кто ставит `isdraftable` при создании франшизы, в коде не найдено. Правило выше выведено из сейвов и сходится
с предсказанием по базе: в первом сейве после создания из 1276 реальных игроков пула 1270 подходят под правило.
Ещё 6 — ветераны, которым конвейер дал «права места» (`proteam` юниора, драфт 1996–2001): игра их права
сбросила (Спецца, Таллиндер, Морроу, Ричардс, Рапп, Поти). Один финн 2009 г. р. в пул не попал: его `draftyear`
— 2028.

Во франшизе у клубов CHL нет записей `leaguerostertable`: составы есть только у НХЛ и АХЛ, юниоры числятся
только по `team` в био. Поэтому убрать ветерана с места юниора франшизе не мешает. Это важно только для «Играть
сейчас», где клубы CHL играют своими составами.

## 4. Что будет с первым драфтом, если убрать переростков

- **Команды проспектов 209/210 пусты или их игроки «ушли».** Это дополнительные записи тех же людей: в пул они
  идут через свой клуб CHL. Пустые 209/210 пул не меняют. Если убрать самих игроков (31), квоты CHL всё равно
  перекрыты, и игра никого не догенерирует.
- **Если старые игроки CHL не draftable при создании, игра сама догенерирует класс.** Проверено в игре
  09.10.2026: свой корень, сборка bin-user, новая франшиза на тестовой базе. В ней всем 1198 старым игрокам CHL
  без прав даны права НХЛ, как у выбранного на драфте 2026, — только для опыта.
  - Итог: `leaguerookiedata` 262 = 235 вымышленных 2007–09 г. р. + 27 финнов, на 224 выбора хватает.
  - Вымышленные по лигам: WHL 40, OHL 40, QMJHL 35 — это квоты CHL. Остальные 8 лиг — 35 / 10 / 15 / 11 / 2 (+27
    финнов) / 21 / 23 / 3, как и раньше, с поправкой на случайные «лишние».
  - Вымышленные идут без клуба (`team` 0), только с `juniorleague`. У них `draftyear` 2025 — 108, 2026 — 131,
    2027 — 23.
  Данными базы так не сделать без вреда: при создании `isdraftable` не зависит от возраста, а `draftyear` игра
  пересчитывает. Права НХЛ у 1198 30-летних — только для опыта: они повисли бы в списках прав клубов. Нужна
  врезка в порт: в 828C91B8 / 8291F160 отбрасывать тех, кому к драфту больше 20 лет. Это решение для
  nhl13-franchise / пользователя.
- **Простая правка `leaguerookiedata` в сейве уже созданной франшизы не прошла.** Пробовали сжать класс до 147
  (current = 147) и убрать переростков в список удалённых, как делает сама игра (alloc 2 → 6), оба раза с
  `isdraftable` = 0 у 1249 игроков. Все суммы были верны, но игра оба раза написала «BE A GM4 appears to be
  damaged». Правка одного номера игрока НХЛ в `leagueplayerbiotable` — тоже. Правка `leaguedraftpick.year` того
  же сейва грузится, у nhl13-franchise и в контроле draftpool. Похоже, игра проверяет согласованность таблиц.
  Вероятно, на класс ссылаются визиты скаутов (`leaguescoutvisits`: 5890 строк `team`/`playerid`). Правило не
  найдено ([save-editing.md](save-editing.md)). Класс на драфте игра не догенерирует: 82934AB8 только
  перечитывает таблицу. «147 на 224 выбора» в игре не проверено. При создании франшизы такого не бывает: по
  квотам игра создаёт ~235 вымышленных, и класс выходит ~262.

**в) Свежие юниорские составы — источники и объём (в сеть не ходил).** Составы OHL, QMJHL и WHL отдаёт API
HockeyTech (`lscluster.hockeytech.com/feed/…`, тот же, что у сайтов лиг): состав, номер, амплуа, хват, дата и
место рождения, рост, вес, статистика. Нужен публичный ключ клиента из JS сайта лиги — это вопрос к
пользователю (тот же «ключ HockeyTech для юниоров»). Ещё источники: статьи клубов в Wikipedia (шаблоны
`{{Ice hockey team player}}`, как у `ahl.py`, но у юниоров часто устаревшие) и NHL Central Scouting
`api-web.nhle.com/v1/draft/rankings/now` — настоящий класс 2027 (Северная Америка и Европа), удобно для команд
проспектов 209/210. EliteProspects — платный API.

Объём: 60 клубов × ~25 = ~1500 игроков на тех же строках (клубы конвейера, как `league.py`):
- сбор и кэш ~3–4 ч;
- запись как своих клубов (обобщить `--league` на CHL) ~4–6 ч;
- рейтинги юниоров по статистике и возрасту ~2–3 ч;
- проверки и «Играть сейчас» ~2 ч, итого ~12–18 ч агентов.

Тогда первый класс — настоящие юниоры CHL без прав НХЛ, родившиеся до 15.09.2009 (`draftyear` ≤ 2027), а
младшие уйдут в следующие классы.
