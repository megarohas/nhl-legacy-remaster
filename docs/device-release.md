# Релиз для другого устройства

Полная свежая папка игры для другого своего ПК: скинул, запустил. Если пользователь просит «подготовь релиз для другого
устройства», нужно сделать то, что написано здесь.

Папка личная: в ней файлы игры EA, сейвы и фото. Её не публикуют, друзьям отдают только без `game\`.

## Как собрать

Игра закрыта, свежая сборка стоит в `nhl-legacy-port/out/build/win-amd64-release`.

```bash
bash tools/device_release.sh --check
```

Результат: `nhl-legacy-port/dist/device/NHL Legacy Remaster vX.Y.Z`, около 8 ГБ, 3–5 минут.

| Шаг | Что происходит |
|---|---|
| проверки | игра закрыта, файлы диска на месте, в дереве сборки нет exe новее установленного |
| папка | `scripts/make_dist.sh --mods`: exe, лаунчер, редактор (папка `editor`, `editor\NHL Legacy Editor.exe`, [editor.md](editor.md)), DLL, настройки без путей к S:, моды, список шейдеров, последние PROFILE и ROSTER |
| файлы игры | `game\`: забираются из прежней папки релиза, с диска копируются только при первом запуске; сверка размеров с диском |
| описание | `release.txt` (версия, коммит, хэши exe и лаунчера), `files.sha256` (все файлы) |
| прежний релиз | в Корзину, с проверкой её квоты (`tools/recycle.py drop`) |
| `--check` | копия папки запускается в `game/work/device-check` до главного меню, журнал проверяется на старые пути, снимок и журнал — `dist/device/check-vX.Y.Z.*`, копия удаляется |

`--no-saves` — без PROFILE и ROSTER (03.11.2026, по просьбе пользователя): игра на устройстве стартует с нуля, составы
берёт из базы, а ростер можно потом добавить вручную через «Обновить ростеры» и проверить импорт. В `release.txt` строка
«сейвы: нет».

Без `--check` проверки запуска нет. С ним нужен свободный `game.lock`: занят — инструмент останавливается, папка при этом
уже собрана, повторить только запуск можно через `--check-only`.

## Порядок для агента

1. Если в `nhl-legacy-port/src` или в лаунчере есть изменения, которых нет в установленной сборке, сначала собрать и
   поставить их ([legacy-port.md](legacy-port.md), «Сборка»), поднять версию, дописать CHANGELOG, поставить метку.
2. Запустить `tools/device_release.sh --check`. Это дольше 30 секунд, поэтому в фоне.
3. Посмотреть снимок: главное меню, окна «ROSTER damaged» нет.
4. Назвать пользователю путь, размер, версию и что изменилось с прошлого релиза.

## Что сделать на устройстве

1. Скопировать папку целиком куда угодно, кроме Program Files.
2. Запустить `nhllegacy_launcher.exe`. Редактор игры — кнопка «Редактор…» в нём или `editor\NHL Legacy Editor.exe` ([editor.md](editor.md)).

**Обновление = скопировать новую папку поверх старой, кроме `saves\`.** С 0.17.0 всё личное (сейвы, профиль, франшизы,
ростеры, настройки лаунчера, ачивки, повторы) лежит в `saves\` и обновлением не перезаписывается и не удаляется. В `saves\`
релиза пусто, стартовые PROFILE и ROSTER лежат в `start-saves\`: игра копирует их в `saves\`, только если там нет сейва этого
вида. Поэтому даже копия поверх вместе с `saves\` ничего не испортит. Новые составы приходят отдельным файлом и ставятся через
«Обновить ростеры» в лаунчере: новый ростер ложится в `saves\rosters` рядом со старыми.

Устройство с версией до 0.17.0: скопировать новую папку поверх старой. При первом запуске игра сама скопирует сейвы из
`userdata\B13EBABEBABEBABE\454109EC\00000001` в `saves\`, старые останутся на месте. Можно и в новую папку: положить туда
`userdata\B13EBABEBABEBABE` от старой версии.

Обновление частями: наш контент лежит по частям в `content\` (database, menus, photos, logos, uniforms, heads, equipment, arenas,
music). Поменялась одна часть — достаточно заменить её папку.

Первый запуск дольше обычного: драйвер собирает шейдеры под эту видеокарту, окно чёрное, сверху справа идёт надпись
«Compiling shaders». На RTX 3060 это 27 секунд (552 пайплайна), на слабой видеокарте дольше. Дальше кэш драйвера помнит
результат: 0,16 с. Если игра тормозит, в лаунчере есть «D3D12 — быстрый» и Vulkan.

Требования: Windows 10/11 x64, DirectX 12 или Vulkan 1.3, процессор с SSE4.1. DLL рантайма лежат в папке, ставить ничего
не нужно.

## Что внутри

| Есть | Нет |
|---|---|
| exe, лаунчер, редактор, DLL | папки установки: её `nhllegacy.toml` с путями к S: |
| моды по частям в `content\` (из `userdata/cache/guest` установки или её `content\`) | кэш самой игры: реклама, повторы, файлы `.ver` |
| `cache\shaders\shareable`, список шейдеров | результат сборки шейдеров драйвером: он свой на каждом ПК |
| последние PROFILE и ROSTER — в `start-saves\`, `saves\` пустая | карьеры: DYNASTY, BEAPRO и другие |
| файлы игры в `game\` | |

Список шейдеров от железа не зависит: `454109EC.xsh` и `.xpso`. Игра собирает всё из него при запуске, поэтому в матчах
докомпиляций почти нет. Полный список есть только для пути ROV, стоящего по умолчанию; для RTV и Vulkan он старый и
неполный.

## Грабли

- Кэш драйвера привязан к пути exe: копия на новом месте собирает шейдеры заново. Поэтому `--check` ждёт строку
  `graphics pipelines` в журнале, а не фиксированное время: нажатия во время сборки теряются, а снимок выходит чёрным.
- Экраны загрузки идут с разной скоростью, таймер расходится с ними. `--check` жмёт A и START, пока игра не запросит
  `nhlstorecfg.xml`: это вход в главное меню. Не дошла за 30 кругов, например из-за окна «damaged», — проверка падает.
- `robocopy /XD game` выбрасывает и `userdata/.../fe/ion/game`: меню становится стоковым. Проверять надо полную копию.

## Обновления частями

Полная папка, `saves\` в ней пустая. На устройстве копировать всё, кроме `saves\`, или только изменившееся: exe, DLL,
лаунчер, части `content\`. `files.sha256` показывает, что поменялось. `game\` на 5,8 ГБ одна и та же во всех версиях.
