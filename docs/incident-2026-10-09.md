# Инцидент 09.10.2026: удаление game\, ref\, best_of_nhl\

## Что пропало

09.10.2026 с 10:51 до 10:53 мимо Корзины удалились:
- почти весь `game\`: сейвы и кэш NHL 13, файлы NHL 13, Legacy, NHL 10/12, дамп NHL 24, вся `game\work`;
- `ref\`;
- содержимое `best_of_nhl\`;
- весь `%TEMP%`, в том числе scratchpad сессии Claude.

Git и `nhl-legacy-port\` (код, codegen, сборки, сейвы и CACHE Legacy) не пострадали.

## Причина

1. **Ссылки.** 08.10 с 19:54 до 22:20 агенты для своих сравнений создали в scratchpad (он лежит
   внутри `%TEMP%`) junction-ы на `game`, `ref`, `best_of_nhl` и их подпапки
   (`mklink /J`, `New-Item -ItemType Junction`).
2. **Чистка.** Портативная сборка видеоконвертера (лаунчер PortableApps на NSIS) при каждом выходе
   «заметает следы». Среди прочего в её скрипте есть `RMDir /r "$TEMP\"` — рекурсивное удаление всего
   `%TEMP%` мимо Корзины. NSIS прошёл по junction-ам в S: и стёр их цели.

**Доказательства:**
- Порядок удаления по времени папок совпадает с алфавитным обходом scratchpad: `art\reg\snapnew\game` → `…\ref` → `baseline\best_of_nhl`.
- Уцелели только 47 файлов, чей путь через `%TEMP%` длиннее 260 символов: NSIS ограничен MAX_PATH.
- Время выхода лаунчера по журналу PCA Windows — 10:53:04, через 2 секунды после последнего удаления.

**Исключено:**
- `git clean`: игнорируемые папки, которые идут раньше по алфавиту, целы.
- Windows PowerShell: в окне удаления не запускался.
- Команды агентов.
- Storage Sense, SilentCleanup и ночная чистка FluentCleaner в 03:00 (она по ссылкам не ходит).
