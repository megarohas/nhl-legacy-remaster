# Текстуры NHL 24 → NHL Legacy: дорожная карта по категориям

Цель пользователя — перенести в Legacy все текстуры NHL 24, натянутые на 3D-модели, там, где модели не сильно
отличаются. Модели, меню и музыку не трогаем.

Разбор — по дампу NHL 24 v1.00 (PS4) и архивам Legacy, офлайн, без запуска игры. Формы подробно — в
`docs/nhl24-uniforms.md`. Инструменты — `tools/fb/`, картинки — `game/work/nhl24/compare/`. Ассеты NHL 24 —
только для личного использования, в git не идут.

## 0. Что уже есть и что мешает

- **Работает:**
  - каталог всех 306 519 текстур (154 556 имён): `game/work/nhl24/catalog/textures.csv`, группы — `prefixes.csv`;
  - выгрузка любой группы в PNG: `python -m fb.extract REGEX --out ПАПКА`;
  - перенос «по поверхности» и гибрид для свитера, офлайн-рендер.
- **Мешает: в дампе нет 9 оглавлений `.toc`** (пропали 09.10, список для PS4 — `game/work/nhl24/need_from_ps4.txt`).
  - Без них не находятся ~8 000 чанков, в том числе 103 свитера из 570.
  - Главное: недоступна геометрия почти всех сеток NHL 24. Внутри res лежит только LOD0 свитеров (25 сеток). У
    шорт, гетр, шлемов, перчаток, коньков, клюшек, вратарской экипировки, ворот и льда буферы вершин лежат в чанках,
    на которые ссылается только TOC.
  - Для переноса через 3D эти сетки нужны (только для расчёта). Обход без TOC — поиск чанка геометрии в CAS по
    размеру буферов и рамке из заголовка сетки (`fb.orphans --streams`). На шортах не сработало (§3), так что
    для 3D-переноса экипировки нужен TOC.

## 1. Сводная таблица: эффект / усилия

точке поверхности (как свитер). **3D + декали** — гибрид: основа через 3D, нашивки и логотипы слоями по правилам.

## 2. Порядок работ

1. **Свитеры всех клубов гибридом** — `fb.kit_hybrid` пакетно по таблице комплектов.
   - Сопоставить комплекты NHL 24 со строками `stockteamjerseys` Legacy: дом, выезд, третья; спецформы — по
     решению пользователя.
   - Добавить `sm`/`nm`: снять рельеф нашивок EA с шаблона или перенести `normal` NHL 24.
   - Упаковка — `kitpaint pack`.
2. **Центр льда всех клубов** (2D, образец есть) и **шрифты номеров** (2D) — часы работы, заметно в каждом матче.
3. **Повторно снять 9 `.toc`** — откроет сетки экипировки и 103 свитера. Пока их нет — поиск сеток по
   содержимому (§3).
4. Шорты и гетры через 3D, затем щит NHL на шортах декалью.
5. Борта: разобрать раскладку `adboard` Legacy, собрать статичную ленту из графики NHL 24.
6. Маски вратарей (itech → модели Legacy), затем клюшки.
7. Остальная экипировка (перекраска по зонам) — по желанию: большой объём при средней заметности.

## 3. Пробные образцы

- **Центр льда SEA** (2D) — `game/work/nhl24/compare/sea_center_ice.png`: NHL 24 / наш нынешний / NHL 24 в
  формате Legacy. Развёртка 1024² — `sea_center_nhl24_to_legacy.png`.
  - Кольцо NHL 24 (r 377–383, цвет 0,50,160) совпадает с кольцом EA в Legacy (r 380,5–385,5, цвет 0,56,165).
  - Полоса под красной линию — прозрачная, как у EA.
  - Надпись «Climate Pledge Arena» у NHL 24 — за кольцом (r 403–500). Ляжет ли она за пределами диска льда
    (r > 388) в Legacy, проверить в игре — сейчас игру не запускаем.
- **Шрифт номеров** — `font_layout_compare.png`: раскладка атласа NHL 24 та же, что у EA в Legacy.
- **Свитер** (гибрид) — `sea_home_best.png`, `sea_home_render.png`, `sea_home_collars.png`.
- **Шорты** — не получилось без TOC.
  - Геометрия `player_pant_common_tightlong_lod0` лежит в чанке, на который ссылается только TOC: 2585 вершин,
    буферы 165 440 + 24 584 Б, GUID — по смещению LOD+0x160 заголовка.
  - Среди 47 911 потоков orphan-участков (`catalog/orphan_streams.jsonl`) нет потока с таким размером — ни целого,
    ни хвоста серии.
  - Значит, буферы хранятся иначе: с выравниванием или вместе с другими данными. Нужен TOC.
  - То же у всей экипировки: только у LOD0 свитеров (25 сеток) геометрия внутри res.
