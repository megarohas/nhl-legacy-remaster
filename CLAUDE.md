# Правила работы в репозитории (для Claude и агентов)

- **Никаких junction и symlink на данные проекта**: `mklink`, `New-Item -ItemType Junction/SymbolicLink`,
  `ln -s`. Нигде, особенно в `%TEMP%` и scratchpad. 09.10.2026 чистка `%TEMP%` прошла по таким ссылкам
  и стёрла `game\`, `ref\`, `best_of_nhl\` ([docs/incident-2026-10-09.md](docs/incident-2026-10-09.md)).
  Нужна копия — копируй.
- **`%TEMP%` и scratchpad одноразовые.** FluentCleaner чистит их каждую ночь в 03:00, портативные
  программы — при выходе. Всё рабочее держи в папке проекта: venv, копии userdata, логи, скриншоты,
  распакованное. Места: `game\work\…`, `legacy-port\…` (в .gitignore).
- **Удаление.** Только в Корзину. Рекурсивное удаление (`rm -rf`, `Remove-Item -Recurse`, robocopy
  `/MIR`/`/PURGE`) — только для своих временных папок и только после проверки, что внутри нет ссылок.
- **Git.**
  - Коммит на каждую фичу, только свои пути (`git commit -- <пути>`), без `git add -A`.
  - После коммита хук сам отправляет всё в зеркало на D: ([docs/backup.md](docs/backup.md)).
  - Данные вне git копирует `tools\backup_data.ps1`.
- **Что не в git и не публикуется.**
  - Файлы игр, сейвы и базы EA живут только в `game\`.
  - Фото NHL, ассеты других игр (NHL 24 и т. д.) и музыка пользователя — только для личного
    использования: не коммитить и не публиковать.
- **NHL Legacy.**
  - Тесты под замком `game.lock`.
  - Игра, запущенная без замка, — это пользователь: поверх неё не запускать и не тестировать.
  - Клавиши — только в своё окно.
  - Сейвы пользователя не трогать, тесты — на копиях userdata.
